### Layout

* Use **Flexbox**, not Grid.
* Header/Navbar at the top.
* Hero image full width with dark overlay.
* Hero text positioned on the left.
* Breadcrumb centered below the Hero.
* Main content: **Filter sidebar + Trips content**.
* Filter sidebar on the left with light blue background.
* Search and Sort controls above the trip cards.
* Trip cards displayed horizontally.
* Each card contains: image → category → title → location → rating → price → Book Now button.
* Cards have rounded corners.
* Main content and sidebar should match the reference spacing and proportions.

### Responsive

* **Desktop:** sidebar left + 3 trip cards in one row.
* **Tablet:** sidebar above/alongside content + 2 cards per row.
* **Mobile:** filter collapses/appears above cards + 1 card per row.
* Keep the layout centered and prevent horizontal overflow.
